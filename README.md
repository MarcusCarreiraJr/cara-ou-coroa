Cara ou Coroa

Aplicativo desenvolvido para a disciplina Programação para Dispositivos Móveis.

Descrição

O aplicativo simula o lançamento de uma moeda, sorteando aleatoriamente entre Cara e Coroa.

Funcionalidades
Sorteio de Cara ou Coroa
Contador de resultados
Botão para reiniciar a contagem
Tecnologias Utilizadas
React Native
Expo
TypeScript
